# DmitScript

`*.quest` — текстовый формат поверх существующего Quest DSL. Он компилируется заранее, поэтому игра получает обычный `QuestDefinition`, а ошибки сценария не попадают в браузер.

```text
::dialogue morning
@bg school-yard-night
@cast Дмит | Мишган

Рассказчик: Утро начинается слишком рано.
Мишган: Уф-уф. Живой?
Дмит: Пока да.

@next answer
::end

::choice answer
@prompt Что сказать?
@cast Дмит | Мишган

- Нормально.
  -> finish
  +relation Мишган 1

- Отстань.
  ? Харизма 3
  -> finish
  !-> finish

- Ответить грубо.
  @say Да отстань уже.
  -> finish
::end

::dialogue finish
Рассказчик: Разговор закончен.
@end
::end
```

Поддерживаются `::dialogue`, `::phone`, `::route`, `::choice` и `::cosmetic`; директивы `@bg`, `@cast`, `@next`, `@end`, `@prompt`, `@continue`, `@contact`, `@time`, `@notify`, `@sound-next`, `@effect-next`, `@cast-next`, `@tone-next`, `@requires`, `@requires-all`, `@requires-any`, `@say`, `@narration`.

В `@cast` можно перечислить всю компанию. На экране всё равно одновременно
показываются только два портрета, а активный портрет выбирается по говорящему.
`*-next` перед `@next` или `@end` применяется к последней реплике текущего узла;
это удобно для флагов и эффектов в финале сцены.

Текст варианта в `::choice` по умолчанию описывает действие и не появляется
отдельной репликой. Чтобы Дмит произнёс конкретную фразу до следующей сцены,
добавьте `@say`. Для описания действия от рассказчика используйте `@narration`.

## Характер и последствия

Шесть внутренних черт Дмита: `Смелость`, `Самообладание`,
`Ответственность`, `Товарищество`, `Хитрость`, `Эмпатия`. Они изменяются в
диапазоне от `-10` до `+10`, не участвуют в случайных бросках и описывают
сформировавшийся характер.

```text
- Встать между Матвеем и Копяром.
  +trait Смелость 1
  +trait Товарищество 1
  -> protect-kopyar

- Промолчать и уйти.
  -trait Смелость 1
  -> leave

- Подменить бутылку.
  @requires-trait Хитрость 4
  -> swap-bottle
```

Для последствий уже после решения используйте `@effect-next trait Смелость 1`.
Ветку расширения можно открыть через `@when-trait Товарищество 4`.
Внешние показатели: `+reputation 1` (авторитет) и `+suspicion 1` (подозрение взрослых).
Для дополнительного варианта при достаточном авторитете используйте
`@when-reputation Авторитет 3` внутри `::extend-choice`.

```powershell
npm run quest:check -- src/chapters/chapter-2/scripts/morning.quest
npm run quest:build -- src/chapters/chapter-2/scripts/morning.quest
```

Для генерации в другой файл: `--out`, для задания ID квеста: `--id`, для начальной сцены: `--start`.
